# Azure AD App Registration

Terraform module to manage an app registration in Microsoft Entra ID (Azure AD).
It can optionally create the enterprise application (service principal), a client
secret with an explicit expiration date, and federated identity credentials (standard
or flexible) so that external workloads can authenticate without a secret.

## Permissions

The identity running Terraform needs one of the following:

* Microsoft Graph application permission `Application.ReadWrite.All`
  (or `Application.ReadWrite.OwnedBy` when it is an owner of the app registrations it manages).
* Entra ID role `Application Administrator` or `Cloud Application Administrator`.

Creating owners referencing other users or service principals also requires
`Directory.Read.All` (or equivalent) to resolve the object IDs.

## Authentication

The `azuread` provider must be configured by the caller of this module. Supported methods include:

* OpenID Connect / dynamic provider credentials (recommended), for example with HCP Terraform
  using `ARM_USE_OIDC`, `ARM_TENANT_ID` and `ARM_CLIENT_ID`.
* Client secret using `ARM_TENANT_ID`, `ARM_CLIENT_ID` and `ARM_CLIENT_SECRET`.
* Azure CLI (for local development only).

## Features

* Creates the app registration (`azuread_application`).
* Optionally creates the enterprise application (`azuread_service_principal`), enabled by default.
* Optionally generates a client secret (`azuread_application_password`) with a mandatory expiration date.
  The value is generated by Entra ID and exposed through the sensitive `client_secret` output.
* Optionally configures one or more federated identity credentials
  (`azuread_application_federated_identity_credential`), for example for HCP Terraform, GitHub Actions or Kubernetes.
* Optionally configures flexible federated identity credentials
  (`azuread_application_flexible_federated_identity_credential`, preview) that match token claims with
  wildcards, so one credential can cover a whole HCP Terraform project (all workspaces and run phases).
  Only supported for GitHub, GitLab and HCP Terraform issuers.

> **Note:** a generated client secret is stored in the Terraform state. Protect the state
> (for example with HCP Terraform remote state) and prefer federated credentials whenever possible.

## Usage example

### App registration with a federated credential (no secret)

```hcl
module "appregistration" {
  source  = "app.terraform.io/<ORGANIZATION>/appregistration/azuread"
  version = "0.0.0"

  display_name = "app-hcp-terraform"

  federated_credentials = {
    tfc-plan = {
      issuer  = "https://app.terraform.io"
      subject = "organization:my-org:project:my-project:workspace:my-workspace:run_phase:plan"
    }
    tfc-apply = {
      issuer  = "https://app.terraform.io"
      subject = "organization:my-org:project:my-project:workspace:my-workspace:run_phase:apply"
    }
  }
}
```

### App registration with a flexible federated credential for a whole HCP Terraform project

```hcl
module "appregistration" {
  source  = "app.terraform.io/<ORGANIZATION>/appregistration/azuread"
  version = "0.0.0"

  display_name = "app-hcp-terraform-project"

  flexible_federated_credentials = {
    tfc-project = {
      issuer                     = "https://app.terraform.io"
      claims_matching_expression = "claims['sub'] matches 'organization:my-org:project:my-project:workspace:*:run_phase:*'"
    }
  }
}
```

### App registration with a client secret

```hcl
module "appregistration" {
  source  = "app.terraform.io/<ORGANIZATION>/appregistration/azuread"
  version = "0.0.0"

  display_name = "app-with-secret"

  secret = {
    end_date = "2027-12-31T23:59:59Z"
  }
}
```

No modules.

## Required Inputs

The following input variables are required:

### <a name="input_display_name"></a> [display\_name](#input\_display\_name)

Description: (Required) The display name of the app registration.

Type: `string`

## Optional Inputs

The following input variables are optional (have default values):

### <a name="input_app_role_assignment_required"></a> [app\_role\_assignment\_required](#input\_app\_role\_assignment\_required)

Description: (Optional) Whether users and groups must be assigned to the enterprise application before they can sign in. Only used when create\_service\_principal is true.

Type: `bool`

Default: `false`

### <a name="input_create_service_principal"></a> [create\_service\_principal](#input\_create\_service\_principal)

Description: (Optional) Whether to create the enterprise application (service principal) associated with the app registration.

Type: `bool`

Default: `true`

### <a name="input_description"></a> [description](#input\_description)

Description: (Optional) A description of the app registration. It is also applied to the enterprise application when create\_service\_principal is true.

Type: `string`

Default: `null`

### <a name="input_federated_credentials"></a> [federated\_credentials](#input\_federated\_credentials)

Description: (Optional) Map of federated identity credentials to configure on the app registration, which allows external workloads to authenticate without a secret. The map key is used as the credential display name.

Type:

```hcl
map(object({
    issuer      = string
    subject     = string
    audiences   = optional(list(string), ["api://AzureADTokenExchange"])
    description = optional(string)
  }))
```

Default: `{}`

### <a name="input_flexible_federated_credentials"></a> [flexible\_federated\_credentials](#input\_flexible\_federated\_credentials)

Description: (Optional) Map of flexible federated identity credentials (preview) to configure on the app registration. They use a claims matching expression (e.g. "claims['sub'] matches 'organization:org:project:proj:workspace:*:run\_phase:*'") instead of an exact subject, so a single credential can cover multiple workspaces and run phases. Only supported by GitHub, GitLab and HCP Terraform issuers. The map key is used as the credential display name.

Type:

```hcl
map(object({
    issuer                     = string
    claims_matching_expression = string
    audience                   = optional(string, "api://AzureADTokenExchange")
    description                = optional(string)
  }))
```

Default: `{}`

### <a name="input_owners"></a> [owners](#input\_owners)

Description: (Optional) List of object IDs (users or service principals) that will be owners of the app registration and of the enterprise application.

Type: `list(string)`

Default: `[]`

### <a name="input_secret"></a> [secret](#input\_secret)

Description: (Optional) Client secret to generate for the app registration. The secret value is generated by Entra ID, stored in the Terraform state and exposed through the sensitive client\_secret output. The end\_date is required and must be an RFC 3339 timestamp (e.g. 2027-12-31T23:59:59Z). When null, no secret is created.

Type:

```hcl
object({
    end_date     = string
    display_name = optional(string, "terraform-managed")
  })
```

Default: `null`

### <a name="input_sign_in_audience"></a> [sign\_in\_audience](#input\_sign\_in\_audience)

Description: (Optional) The Microsoft identity platform audiences supported by the app registration. Possible values are AzureADMyOrg, AzureADMultipleOrgs, AzureADandPersonalMicrosoftAccount or PersonalMicrosoftAccount.

Type: `string`

Default: `"AzureADMyOrg"`

## Outputs

The following outputs are exported:

### <a name="output_application_id"></a> [application\_id](#output\_application\_id)

Description: The resource ID of the app registration (/applications/{object\_id}).

### <a name="output_application_object_id"></a> [application\_object\_id](#output\_application\_object\_id)

Description: The object ID of the app registration.

### <a name="output_client_id"></a> [client\_id](#output\_client\_id)

Description: The client ID (application ID) of the app registration.

### <a name="output_client_secret"></a> [client\_secret](#output\_client\_secret)

Description: The generated client secret value. Null when no secret is requested.

### <a name="output_client_secret_end_date"></a> [client\_secret\_end\_date](#output\_client\_secret\_end\_date)

Description: The expiration date of the generated client secret. Null when no secret is requested.

### <a name="output_display_name"></a> [display\_name](#output\_display\_name)

Description: The display name of the app registration.

### <a name="output_federated_credential_ids"></a> [federated\_credential\_ids](#output\_federated\_credential\_ids)

Description: Map of federated identity credential IDs, keyed by the credential display name.

### <a name="output_flexible_federated_credential_ids"></a> [flexible\_federated\_credential\_ids](#output\_flexible\_federated\_credential\_ids)

Description: Map of flexible federated identity credential IDs, keyed by the credential display name.

### <a name="output_service_principal_object_id"></a> [service\_principal\_object\_id](#output\_service\_principal\_object\_id)

Description: The object ID of the enterprise application (service principal). Null when create\_service\_principal is false.
